# pawbot 0.3.3 release notes

This patch fixes the first-run experience for the native terminal client,
provider setup, and WebUI deployments on remote machines.

## Fixed

- Published native TUI archives for Linux x64/ARM64, macOS Intel/Apple Silicon,
  and Windows x64. Released packages download the matching archive on first
  `pawbot agent` launch and verify its checksums and bundled notices.
- Restored the release-download fallback for packaged installations while
  keeping source checkouts on their own Bun-managed TUI build.
- Quick Start now probes a configured compatible provider's `/models` endpoint,
  selects an available model, and enriches it with the shared capability table.
  Known models such as DeepSeek V4 Flash carry their 1M context window and
  supported reasoning levels into the generated preset.
- Kept manual model entry as a clear fallback for providers that do not expose a
  compatible model catalogue.
- Added `pawbot webui --host <bind-host>` for explicit remote WebUI deployment,
  with authentication, firewall, gateway-health, and SSH-tunnel guidance. The
  default remains localhost-only.
- Restored registry-backed model autocomplete and context-window recommendations
  in the terminal onboarding flow.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
```

Existing configuration and session data remain in the user's pawbot data
directory. The first native TUI launch after upgrading downloads one
platform-matched release archive into the local data directory.
