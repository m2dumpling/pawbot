# pawbot 0.3.1 release notes

This release strengthens pawbot's execution boundaries and makes Record &
Replay useful as a local engineering diagnostic rather than only a pass/fail
report.

## Highlights

- Added turn-level budgets for iterations, tool calls, wall time, tokens, and
  optional cost estimates.
- Added explicit tool lifecycle evidence, including cancelled calls whose side
  effects cannot be confirmed.
- Made oversized structured tool results stable, atomic, and recoverable.
- Added deterministic recursive glob matching and summary checkpoints.
- Added WebUI replay diagnostics, a concise `pawbot replay` command, and local
  replay benchmark output.
- Added a dedicated Record & Replay fixture job and core Provider/Tool/Session
  contract tests to CI.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
pawbot
```

Existing configuration, sessions, workspaces, and recordings remain under the
user's local `~/.pawbot/` data directory.

## Boundaries

- Replay verifies current orchestration against recorded rails; it does not
  make a live provider deterministic.
- Multi-instance durable execution and distributed failover remain outside
  this release.
