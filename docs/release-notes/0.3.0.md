# pawbot 0.3.0 release notes

This page is the release-note draft for the current 0.3.x development line.
It is not a promise of hosted services or distributed deployment guarantees.

## Highlights

- WebUI, CLI, gateway, channel, SDK, and OpenAI-compatible API entry points.
- Explicit AgentLoop turn stages and AgentRunner ReAct execution.
- Provider/model routing, tools, MCP, sessions, memory, automation, and context governance.
- Record & Replay for offline provider/tool-rail replay and structural regression diffs.
- Python lint, strict type checking, WebUI tests/build, and package smoke verification.

## Record & Replay

```bash
pawbot agent --message "inspect the repository" --record .pawbot/blackbox/run-1
pawbot agent --replay .pawbot/blackbox/run-1
```

Replay artifacts can contain prompts, tool results, local paths, and other
private data. Sanitize them before sharing.

## Known boundaries

- The default bus and agent state are process-local.
- Multi-instance consistency, durable distributed execution, and automatic
  failover are outside this release line.
- Provider, MCP, and channel behavior depends on the selected integration and
  its credentials or network availability.
