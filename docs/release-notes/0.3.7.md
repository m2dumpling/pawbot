# pawbot 0.3.7 release notes

This patch release cleans up the native TUI's model presentation so the active
model has one clear, current label.

## Fixed

- Avoided showing the same model twice when a preset ID equals the active model
  ID.
- Removed stale model and access text from the static welcome card; the live
  title controls now own those values.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
```

Existing configuration, sessions, and recordings remain in the user's Pawbot
data directory.
