# pawbot v0.7.3

This patch release fixes two WebUI reliability issues in the v0.7.2 task
evaluation and long-running task controls.

## Fixed

- Custom task evaluation cases can now be removed from the WebUI. The delete
  action is registered and routed through the authenticated WebUI mutation
  dispatcher.
- Stopping a long-running WebUI task now terminates child execution before the
  active turn is joined. The WebUI also ignores late events from the stopped
  turn, so repeated clicks no longer race with stale streaming state.
