# Pawbot v0.8.1：委派权限、任务停止与 MCP 重连修复

已发布：[GitHub Release](https://github.com/m2dumpling/pawbot/releases/tag/v0.8.1)、
[PyPI pawbot-ai 0.8.1](https://pypi.org/project/pawbot-ai/0.8.1/)。
发布 tag 指向绿色 main 提交 `7d69e35`，五个平台 TUI 归档及对应 SHA-256 文件均已上传。

本版修复 Agent 委派任务时的权限和审批继承、停止后旧结果的处理，
以及 MCP 旧版 HTTP 会话过期后的重连。现有配置可以继续使用。

## 用户可感知的修复

- 同步和后台子 Agent 继承发起回合的能力限制、审批范围及恢复确认。
  主任务禁止的能力不能通过委派获得；批准委派后，子任务的写入等操作
  仍按配置单独审批。独立使用 SubagentManager 时也保留其配置的能力限制。
- 停止会话时使未消费的子任务结果失效，包括已经进入消息总线或等待会话锁的结果。
  旧结果不会启动后续模型回合或混入新的用户回合；有效结果只消费一次，
  停止其他会话不会影响本会话的有效结果。
- MCP 旧版 HTTP 会话返回 SDK v2 的 `-32600 / Session not found` 时重新连接。
  普通工具错误或参数错误不会被当作会话失效处理。

## 开发验证与可复现证据

- 新增 29 项委派专项回归，覆盖权限拒绝、独立审批、超时、取消、会话和工作区隔离、
  恢复确认及 SDK 兼容性。
- WebUI 与 TUI 的实际客户端分别连接真实 Gateway 和本地脚本 Provider，
  覆盖同步/后台委派的批准、拒绝、停止，以及中断恢复的继续、放弃，共每客户端 8 条流程。
  两项客户端集成测试已加入 CI 必跑步骤。
- MCP 生命周期测试启动真实本地 HTTP 服务，验证空闲过期后的重连及重连中关闭。
  测试服务无法启动时会直接失败并提供诊断。
- 提供[固定条件下的修复案例](../experiments/subagent-policy-regression.zh-CN.md)
  和[机器可读结果](../experiments/subagent-policy-regression.json)：
  委派权限主案例从 3/9 通过到 9/9，停止后旧结果从 0/2 到 2/2，
  MCP 空闲过期重连从失败到通过。
- 更新中英文 README 的案例导航、控制流与 Harness 文档，修复开发指南链接。

## 升级与边界

通过 `uv tool install --force --upgrade pawbot-ai` 升级，
运行 `pawbot --version` 确认版本为 `0.8.1`。原有 Provider 配置和会话数据继续使用。
使用原生 TUI 的安装必须搭配同一版本的发布归档。

本次结果是脚本 Provider 驱动真实运行链路的工程回归，未新增真实模型评测，
不代表生产任务准确率或成本改善。审批与路径检查不等同于操作系统沙箱；
停止不能撤销已经发生的外部写入。子任务未新增独立的跨重启续跑保证。

发布与安装验收步骤见[发布指南](../publishing.md)。
