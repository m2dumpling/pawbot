# Pawbot v0.8.3

This patch improves error handling when the native TUI is downloaded for the
first time. The changes in [v0.8.2](https://github.com/m2dumpling/pawbot/releases/tag/v0.8.2)
remain included.

## Fixed

- Certificate verification, other TLS errors, HTTP errors and network failures
  are reported separately from a missing release archive. The error message
  suggests what to check and explains how to use `pawbot agent --classic`.
- Temporary network errors, rate limiting and selected server errors are
  retried once. Certificate errors and authorization failures are not retried.
  An invalid checksum file is reported explicitly.

TLS certificate verification and archive integrity checks remain enabled. A
certificate error may still require correcting the local system clock, trust
store or network configuration; this release does not bypass those checks.

## Installation and evaluation

Install with `pip install -U pawbot-ai` or see the
[installation guide](https://github.com/m2dumpling/pawbot#installation).
The [Promptfoo evaluation suite](https://github.com/m2dumpling/pawbot/tree/main/evals/promptfoo)
is a developer tool in the source repository and is not bundled with the
Python wheel.
