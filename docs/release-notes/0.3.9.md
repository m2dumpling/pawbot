# pawbot 0.3.9 release notes

This patch release improves remote terminal usability, optional HTTP recording,
and self-updating for existing installations.

## Added

- Added `pawbot update`. It detects the active uv, pipx, or pip installation
  method, upgrades Pawbot to the latest compatible release, and does not rerun
  onboarding.
- Added the `recording` optional extra for vcrpy HTTP cassette support.
- Added regression coverage for real HTTPX cassette recording and playback.

## Fixed

- The native TUI now disables mouse reporting by default in SSH and Mosh
  sessions, allowing terminal clients such as Termius to provide native text
  selection and copy behavior. Set `PAWBOT_TUI_MOUSE=1` to opt back in to TUI
  mouse events.
- Remote `Ctrl+V` is no longer interpreted as a server-side image clipboard
  request. Use the terminal client's Paste action or Paste mode for text input.

## Upgrade

Existing installations can update without repeating Provider or API Key setup:

```bash
pawbot update
```

The command leaves Provider credentials, channel configuration, sessions,
recordings, and workspaces in place. Source/editable installations should still
be updated with their normal Git checkout workflow.

Optional HTTP cassette support can be installed with:

```bash
uv tool install --force --upgrade "pawbot-ai[recording]"
```
