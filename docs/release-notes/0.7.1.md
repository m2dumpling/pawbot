# pawbot v0.7.1

This patch improves Agent reply and WebUI response speed. Long-running Agent
tasks no longer block the loading of other WebUI settings and controls.

## Changes

- Gateway event-journal persistence and replay I/O no longer block the
  asyncio event loop.
- Event-journal retention is bounded and reconnect recovery continues after a
  retained-event gap.
- Turn context construction reuses the exact system prompt used for token
  reservation and moves filesystem-heavy work away from the Gateway loop.
- Windows CLI Apps catalog loading avoids repeated PATH probing while keeping
  authoritative checks for installed applications.

## Verification

The release candidate passed the complete GitHub Actions matrix on Python 3.11
for Linux and Python 3.13 for Windows, plus WebUI, native TUI, package smoke,
Record & Replay, installer smoke tests, and the quality gate.
