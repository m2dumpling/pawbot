# pawbot v0.7.0

This release adds a repeatable live-model evaluation workflow, an optional OTLP
exporter, and MCP SDK v2 compatibility. The normal WebUI navigation and daily
chat workflow are unchanged.

## Highlights

- Run `pawbot eval live list`, `run`, and `compare` against a versioned set of
  20 public synthetic incident-triage cases. Each trial uses fresh local fake
  APIs and a temporary workspace. Real provider calls require an explicit cost
  cap and configured token prices.
- Inspect outcome, tool trajectory, safety, token/cost, latency, and per-trial
  trace results. Export a rolling replay candidate as a live case only after
  supplying a reviewed, sanitized case payload.
- Enable the optional `otel` extra to send bounded Agent spans and metrics to
  an OTLP endpoint. It is off by default; local Trace and replay still work
  without network telemetry.
- Connect to MCP servers through the v2 Python SDK. Pawbot uses modern discovery
  first and falls back to the older handshake only when the server reports
  method-not-found. HTTP transport and OAuth callback checks were updated.
- See token-estimation source in local Trace and the documented boundaries for
  checkpoint recovery, approvals, tool retries, and external side effects.

## WebUI

No new WebUI page or control was added for live evaluation or OTLP setup. The
existing chat, local Trace, Record & Replay, and MCP settings remain in place.
The MCP OAuth callback now rejects duplicate security parameters and passes the
issuer value to the SDK for validation.

## Evaluation boundaries

The bundled 20 cases are synthetic. The saved DeepSeek responses were regraded
offline after the keyword oracle was corrected; that same sample helped calibrate
the oracle, so the resulting score is not an independent measure of production
Agent quality. The optional Judge uses the same provider as generation and has
not been independently calibrated with human labels. Use real sanitized failures
and a separate holdout before treating live scores as a release threshold.

both wheel and sdist, WebUI home and gateway health, a real chat request, Trace,
offline replay, a Microsoft Learn MCP connection, CLI/catalog version, Ruff,
basedpyright, and lock consistency.

skipped, 82.82% coverage). WebUI, native TUI, package smoke, Record & Replay,
