# pawbot 0.3.6 release notes

This release improves provider setup and makes Record & Replay distinguish an
unchanged replay from problems that occurred during the original Agent run.

## Fixed

- Separated replay consistency from original execution health in the WebUI.
- Added visible model-request failure cards with provider status and error
  metadata.
- Added headless Linux WebUI guidance and the `pawbot webui --remote` shortcut.
- Added the stable `x-opencode-session` header required by OpenCode Go.
- Localized the complete Record & Replay settings surface in English and
  Chinese.

## Added

- Added live provider model discovery to the TUI model picker and `/model` and
  `/models` commands.
- Added session-scoped model selection without rewriting global configuration.
- Made curated context-window and reasoning metadata authoritative for known
  models.
- Added native Anthropic model discovery with context and reasoning metadata.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
```

Existing configuration, sessions, and recordings remain in the user's Pawbot
data directory.
