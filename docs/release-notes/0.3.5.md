# pawbot 0.3.5 release notes

This release makes Record & Replay useful as a readable explanation of what an
Agent turn actually did, while keeping the complete raw evidence available for
debugging.

## Changed

- Expanded replayed turns into a conversation-like execution trace containing
  the user request, provider-returned thinking records, model decisions, tool
  calls, tool arguments, tool results, and final answer in event order.
- Added compact previews and in-place expansion for long model output, tool
  arguments, tool results, and thinking records.
- Kept full JSON/JSONL data behind the dedicated full-screen **View raw record**
  action so normal inspection is understandable without losing forensic detail.
- Updated the UI and documentation to explain that a green replay result means
  no observable difference was found under fixed recorded inputs, model
  responses, and tool observations. It is not a model-quality score.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
```

Existing configuration, sessions, and recordings remain in the user's Pawbot
data directory.
