# Pawbot v0.8.2

This release fixes misleading subagent completion messages and adds a small,
reproducible workspace evaluation suite for developers.

## Fixed

- A subagent that reaches an execution limit, returns no answer, or fails a
  requested task verification is reported as incomplete instead of successful.
  Its stop reason and partial result remain available for both synchronous and
  background delegation. The change does not retry work automatically or undo
  side effects already performed by a tool.

## Developer evaluation

- Six controlled workspace tasks exercise file reading, code repair, config
  migration, log analysis, and read-only behavior. Each trial uses a fresh
  temporary workspace, and independent checks inspect the resulting files and
  tool trajectory. Four cases are for development and two are held out from
  tuning; the holdout tasks are public and are not a benchmark.
- A recorded small-sample run using a real model passed 18 of 18 trials. This
  measures those fixed tasks only, not production accuracy. The workspace
  suite does not exercise subagent delegation; dedicated regression tests cover
  the subagent fix. See the [experiment evidence](https://github.com/m2dumpling/pawbot/blob/v0.8.2/docs/experiments/agent-evaluation-evidence.md)
  for conditions, token usage and limitations.
- The [Promptfoo guide](https://github.com/m2dumpling/pawbot/blob/v0.8.2/evals/promptfoo/README.md) is in the source
  repository and the evaluation directory is not bundled with the wheel.
  Temporary workspaces are not operating-system security sandboxes; execute
  generated code only in an appropriately controlled environment.

## Release validation

The release workflow verifies the five native TUI archives and their checksums.
Python distributions are built and tested in a separate prepare run; the
publishing run verifies and uploads those exact distributions. See the
[publishing guide](https://github.com/m2dumpling/pawbot/blob/v0.8.2/docs/publishing.md) for the release and installation checks.
