# pawbot 0.3.4 release notes

This patch makes Record & Replay easier to understand and inspect in the
WebUI without hiding the complete execution evidence.

## Changed

- Reworked each replayed turn around a compact summary showing the user
  request, final answer, selected model, model decision count, tool-call count,
  execution outcome, and a short execution path.
- Added a dedicated full-screen **View raw record** surface for the complete
  turn envelope and ordered `tools.jsonl` records. The raw view keeps the
  original JSON data visible without putting every diagnostic field in the
  default turn layout.
- Reworded the report so a green result means **no observable difference was
  found under the recorded inputs, model responses, and tool results**. It is
  an offline orchestration regression check, not a model-quality score.

## Upgrade

```bash
uv tool install --force --upgrade pawbot-ai
```

Existing configuration, sessions, and recordings remain in the user's Pawbot
data directory.
