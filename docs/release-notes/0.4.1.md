# pawbot 0.4.1 release notes

This release adds task-oriented Agent Harness fixtures and clearer benchmark
metrics. It makes the difference between “the execution path stayed stable” and
“the task met its contract” visible in both local output and CI.

## Added

- Added `workspace-change-and-verify`, a deterministic multi-step task that
  writes to an in-memory workspace, reads the value back, and checks the final
  verification statement.
- Added `investigate-and-summarize`, a deterministic task that searches an
  incident, inspects its details, and checks the resulting summary.
- Added Harness summary metrics for evaluable tasks, task pass rate, model
  requests, Tool attempts, and Tool failures.
- Added the public [Agent Harness experiment baseline](../experiments/agent-harness-baseline.md),
  including the evaluation method, fixture catalog, reproducibility commands,
  result interpretation, and boundaries.

## Changed

- The CI quality gate now prints the complete JSON Harness report as a separate
  step, making trajectory and task-level evidence visible in workflow logs.

## Baseline result

The nine built-in scenarios are expected to produce 9/9 passing trajectories,
5/5 passing evaluable tasks, 0 task failures, and 4 boundary scenarios marked
`task: not_evaluable`. The report also records 17 model requests, 10 Tool
attempts, and 3 Tool failures for this fixed catalog; elapsed time is local
environment data, not a portable performance claim.

## Upgrade

Existing installations can update without repeating Provider or API Key setup:

```bash
pawbot update
```

The command keeps existing Provider credentials, sessions, recordings, and
workspaces. Source/editable installations should continue to use their normal
Git checkout workflow.
