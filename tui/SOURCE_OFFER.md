# Written offer for corresponding source

This offer applies to the native pawbot TUI executable distributed in the same release archive.

For at least three years after the release date, the pawbot release publisher offers any third party a
complete machine-readable copy of the corresponding source and relinking materials required for
the LGPL-covered libraries incorporated through Bun, for no more than the reasonable physical
cost of conveying that copy.

The pawbot application source, lockfile, build scripts, notices, and relinking instructions are
already included in this archive. Exact upstream revisions are listed in `RELINKING.md`.

To request any additional corresponding-source material, use the issue tracker
of the repository that published the archive and identify the pawbot release
tag and target platform shown in `THIRD_PARTY_NOTICES.txt`.
